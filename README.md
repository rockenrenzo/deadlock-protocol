Hola! This is a tactial stealth and vault extraction puzzle game built that runs inside of your terminal :)
you have to dodge patrolling guards and stay out of their line of sight, time your moves through cycling laser grids, hack a 4 bit security terminal for the keycard, breach the vault, and escape before hte lockdown timer hits zero!

## HOW THIS PROJECT WAS CREATED
This project was made with [Python 3](https://python.org) using only standard built-in libraries ("random", "time", and "sys") so anybody can run it right in their terminal with zero extra installations  :D As an add on this project was coded inside of Visual Studio Code(https://visualstudio.com)

## How TO RUN THE PROJECT
1. Clone the source code to your device
``` sh
git clone https://github.com/rockenrenzo/deadlock-protocol.git
```

2. Open the project folder!
```sh
cd deadlock-protocol
```

3. Run the game in your terminal
```sh
python deadlock_protocol.py
```

4. Use `W`, `A`, `S`, `D` to move, `X` to wait a turn, and have fun!
